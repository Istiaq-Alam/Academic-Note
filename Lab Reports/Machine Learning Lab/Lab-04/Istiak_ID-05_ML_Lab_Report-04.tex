\section{Objective}
The objective of this experiment is to understand and implement data preprocessing and unsupervised learning techniques in Machine Learning. Specifically, this lab focuses on applying Label Encoding and One-Hot Encoding to transform categorical data into numerical format suitable for machine learning models. Additionally, the experiment aims to apply the K-Means Clustering algorithm to group similar data points based on feature similarity.

The goals of this experiment are:
\begin{itemize}
    \item To learn how to convert categorical variables into numerical representations using Label Encoding and One-Hot Encoding.
    \item To analyze the impact of encoding techniques on dataset structure.
    \item To implement the K-Means clustering algorithm for unsupervised learning.
    \item To identify natural groupings (clusters) in customer data based on features such as income and spending behavior.
    \item To visualize clusters and interpret patterns in the dataset.
\end{itemize}

\section{Dataset Description}

\subsection*{Encoding Dataset (encoding.csv)}
The dataset \texttt{encoding.csv} is used to demonstrate categorical data preprocessing techniques. It contains one or more categorical features such as gender, country, or other non-numeric attributes.

Key characteristics:
\begin{itemize}
    \item Contains categorical variables that cannot be directly used in machine learning models.
    \item Used to apply Label Encoding, where each category is assigned a unique integer.
    \item Used to apply One-Hot Encoding, where categorical values are converted into binary columns.
    \item Helps in understanding how different encoding techniques affect data representation.
\end{itemize}

\subsection*{Mall Customer Dataset (Mall\_Customers.csv)}
The dataset \texttt{Mall\_Customers.csv} is used for K-Means clustering. It contains customer information collected from a shopping mall.

Typical attributes include:
\begin{itemize}
    \item \textbf{CustomerID}: Unique identifier for each customer
    \item \textbf{Gender}: Male or Female
    \item \textbf{Age}: Age of the customer
    \item \textbf{Annual Income (k\$)}: Customer's yearly income
    \item \textbf{Spending Score (1-100)}: Score assigned based on purchasing behavior
\end{itemize}

\section{Label and Onehot Encoding}

\subsection{Label Encoding on Categorical Data}

\subsection*{Explanation}
In this step, the dataset \texttt{encoding.csv} is loaded using the \texttt{pandas} library. The dataset contains categorical features such as \texttt{Color} and \texttt{Size}, which cannot be directly used in machine learning models.

To convert these categorical values into numerical form, \texttt{LabelEncoder} from \texttt{sklearn.preprocessing} is used. Label Encoding assigns a unique integer value to each category in a column.

For example:
\begin{itemize}
    \item \texttt{Color}: Red, Green, Blue $\rightarrow$ 2, 1, 0 (mapping may vary)
    \item \texttt{Size}: Small, Medium, Large $\rightarrow$ 2, 1, 0 (mapping may vary)
\end{itemize}

Two new columns are created:
\begin{itemize}
    \item \texttt{Color\_LabelEncoded}
    \item \texttt{Size\_LabelEncoded}
\end{itemize}

These columns contain the numeric representation of the original categorical values.

\subsection{One-Hot Encoding of Categorical Features}

\subsection*{Explanation}
In this step, One-Hot Encoding is applied to the categorical columns \texttt{Color} and \texttt{Size} using the \texttt{pd.get\_dummies()} function from the pandas library. One-Hot Encoding converts each unique category value into a separate binary column. Instead of assigning a single numeric label (as in Label Encoding), it creates multiple columns, where:
\begin{itemize}
    \item Each column represents one category
    \item Values are either 0 or 1
    \item 1 indicates the presence of that category, and 0 indicates absence
\end{itemize}

The parameter \texttt{columns=['Color','Size']} specifies which columns to encode, and \texttt{prefix} is used to name the new columns clearly.

As a result, the original \texttt{Color} and \texttt{Size} columns are removed and replaced with multiple new binary columns such as:
\begin{itemize}
    \item \texttt{Color\_Red, Color\_Green, Color\_Blue}
    \item \texttt{Size\_Small, Size\_Medium, Size\_Large}
\end{itemize}

\subsection{K-Means Clustering Implementation}

\subsection*{Explanation}
In this step, the K-Means clustering algorithm is applied using the \texttt{sklearn.cluster} library. The dataset is grouped based on two features: \texttt{score} and \texttt{income}. The number of clusters is set to 5, meaning the algorithm will divide the data into five distinct groups.

The K-Means algorithm works by:
\begin{itemize}
    \item Randomly initializing 5 cluster centroids.
    \item Assigning each data point to the nearest centroid.
    \item Updating centroids based on the mean of assigned points.
    \item Repeating the process until convergence.
\end{itemize}

After fitting the model, the cluster centroids are extracted using \texttt{cluster\_centers\_}, which represent the central point of each cluster.

\subsection{K-Means Clustering (Elbow Method - WCSS Calculation)}

The process calculates the Within-Cluster Sum of Squares (WCSS) for different values of \(k\) (number of clusters). WCSS measures how compact the clusters are; lower values indicate better clustering.

A loop is used to test cluster values from 1 to 11. For each value of \(k\), the KMeans algorithm is trained, and the inertia (WCSS value) is stored in a list.

This helps in identifying the "elbow point", where increasing clusters no longer significantly reduces WCSS.

\subsection{Showing the values of WCSS (Within-Cluster Sum of Squares)}
\subsection*{Explanation}
WCSS (Within-Cluster Sum of Squares) is a metric used in K-Means clustering to measure the compactness of clusters. It calculates the sum of squared distances between each data point and the centroid of its assigned cluster. A lower WCSS value indicates that data points are closer to their respective cluster centers, meaning better clustering performance.

WCSS is commonly used in the Elbow Method to determine the optimal number of clusters (K). As the number of clusters increases, WCSS decreases, and the "elbow point" helps identify the most suitable value of K.
