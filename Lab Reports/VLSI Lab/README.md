# Instruction:
## Download the Zip file or the tex file with logo

## For TexMaker : 
- Go to Option, then Configure Texmaker
- From the tab Open Quick Build
- Select the Quick Build Command to - **XeLaTex + ViewPDF**
- Save and Run

## For Overleaf: 
- Open the Project file and go to Settings
- From the tab Open Compiler
- Set the Compiler to **XeLaTex** 
- Save and Run
